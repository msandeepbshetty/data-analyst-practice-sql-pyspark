# Data Analyst Practice – SQL and PySpark

This repository contains practical SQL and PySpark exercises designed for learners preparing for Data Analyst roles. The examples focus on real analytics tasks such as queries, joins, aggregations, Spark DataFrames, UDFs, lazy evaluation, and transformations.

## Contents

### SQL
Beginner‑friendly SQL practice covering:
- Select statements
- Filtering and sorting
- Joins
- Aggregations
- Grouping
- Interview‑style query problems

### PySpark
Hands‑on PySpark examples including:
- SparkSession setup
- DataFrame creation
- Lazy evaluation demonstration
- UDF creation and usage
- Column transformations
- Window functions
- Practical patterns used in analytics workflows

## Purpose
This repository helps aspiring Data Analysts build confidence with tools commonly used in modern data teams. The exercises are simple, clear, and suitable for interview preparation or self‑study.

## How to Use
Open the SQL and PySpark folders to access the practice files. Each file contains examples you can run and modify to strengthen your understanding of analytics concepts.
